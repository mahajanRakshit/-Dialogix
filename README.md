# Dialogix – Interactive Chat Application

A responsive front-end chat application demo built with HTML, CSS, and vanilla JavaScript.

## Features
- Responsive desktop and mobile chat interface
- Send messages with Enter or the send button
- Suggested prompt buttons
- Sample automated replies
- Message timestamps
- Save conversation history in browser localStorage
- Clear or start a new conversation

## Technologies
HTML5 · CSS3 · Vanilla JavaScript

## Run Locally
1. Clone or download this repository.
2. Open the `dialogix` folder.
3. Open `index.html` in a modern browser.

No package installation or build step is required.

## Demo Limitation
This is a front-end demonstration. Replies are generated by simple rules in `js/app.js`; the app is not connected to a live AI model, backend, or other users. Messages are stored only in the current browser and do not sync across devices. A real multi-user chat service requires a secure backend and real-time messaging infrastructure.

## Deploy with GitHub Pages
1. Upload the complete project to a public GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/(root)`, then click **Save**.
5. Wait for the published URL to appear in the Pages section.
